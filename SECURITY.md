# Security policy

## Supported versions

None yet. Atrium is at the design stage and has no code and no release. Report a problem in anything committed to this repository as described below.

## Reporting a vulnerability

Do not open a public issue, discussion, or pull request for a security problem.

Email **security@dcyfr.ai** with:

- what you found, and where (file, commit, or document);
- steps to reproduce, if there is code to run;
- the impact you expect.

We will acknowledge the report and agree on a disclosure date with you before anything is published.
